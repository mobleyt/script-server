Spreadsheet format · download a template
  • The first row holds the column headers. Title is required.
  • Access: public, private, restricted or internal. If it’s blank, {{ default_access }} is used.
  • Custom Unique Identifier is optional. Rows whose identifier already exists in Aviary are skipped, so you can safely re-run a file.
  • Featured is optional: yes or no.
  • Media URL: a link Aviary can download. Add more with Media URL 2, Media URL 3… or put several in one cell.
  • Every other column is an Aviary metadata field, named exactly as in Aviary, e.g. Description. To set a vocabulary term, add it in parentheses: Agent (Creator).
  • Separate several values in one cell with {{ delimiter }}, e.g. Smith, Jane {{ delimiter }} Doe, John. Repeating a column also works.
